MON MÉLI-MÉLO — APPLICATION ANDROID

Ce ZIP contient le projet Android à compiler en ligne sur GitHub Actions.
Il ne contient PAS encore d’APK.

1. Créer un dépôt GitHub privé.
2. Déposer à la racine du dépôt le contenu de ce ZIP, en conservant le dossier .github/workflows.
3. Onglet Actions > Fabriquer APK Android > Run workflow.
4. À la fin, ouvrir le résultat du workflow et télécharger l’artifact Mon-meli-melo-APK.
5. Décompresser l’artifact et transférer app-debug.apk sur Samsung.
6. Ouvrir l’APK et autoriser l’installation depuis cette source si Android le demande.

ATTENTION : Version de test non signée pour distribution (APK debug signé automatiquement par les outils Android). Les données des versions HTML ne sont pas migrées automatiquement. Exporter la sauvegarde de l'ancienne version avant installation. La reconnaissance IA des photos et les notifications garanties en arrière-plan ne sont pas incluses.
